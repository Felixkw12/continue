---

[Opper](https://opper.ai) is an EU-hosted AI gateway: 700+ models from 50+ providers behind one OpenAI-compatible API and one key. Model ids are pool names such as `claude-sonnet-4-6`, and Opper picks the route for each request. To pin one provider or region, use a `provider/model` id such as `anthropic/claude-sonnet-4-6`.

<Info>
  You can get an API key from
  [platform.opper.ai](https://platform.opper.ai).
</Info>

## Chat Model

We recommend configuring **claude-sonnet-4-6** as your chat model.

<Tabs>
    <Tab title="YAML">
    ```yaml title="config.yaml"
    name: My Config
    version: 0.0.1
    schema: v1

    models:
      - name: Claude Sonnet 4.6
        provider: opper
        model: claude-sonnet-4-6
        apiKey: <YOUR_OPPER_API_KEY>
        roles:
          - chat
    ```
    </Tab>
    <Tab title="JSON">
    ```json title="config.json"
    {
      "models": [
        {
          "title": "Claude Sonnet 4.6",
          "provider": "opper",
          "model": "claude-sonnet-4-6",
          "apiKey": "<YOUR_OPPER_API_KEY>"
        }
      ]
    }
    ```
    </Tab>
</Tabs>
